핵심 흐름

  • Frontend는 Gateway만 호출합니다.
  • 텍스트 분석·채팅·재분석은 Gateway가 Agent를 직접 호출합니다.
  • 영상 업로드는 Worker가 전처리한 뒤 Agent 판단으로 연결됩니다.

서비스 경계

  • Worker는 장기 영상 처리와 프레임 관찰값 생성 전용입니다.
  • Agent는 party guard, KNIA/Legal 근거 검색, 과실 판단을 담당합니다.
  • KNIA/Legal은 별도 MSA가 아니라 DB에 적재된 지식 소스입니다.
