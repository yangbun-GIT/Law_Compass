Product

LawCompass가 해결하는 문제

사고 직후 사용자는 “내가 무엇을 해야 하는지”, “비슷한 기준이 있는지”, “영상에서 무엇이 확인됐는지”를 한 화면에서 이해해야 합니다.

03

사용자 문제

  • 블랙박스, 현장 사진, 상대 정보, 보험 접수를 어떤 순서로 처리해야 하는지 모릅니다.
  • KNIA 기준 원문은 유용하지만 사고 상황과 연결하기 어렵습니다.
  • 영상·진술·법령 근거가 섞이면 무엇이 확정이고 무엇이 보류인지 알기 어렵습니다.

제품 해법

  • 영상 우선 입력과 guided question으로 사실 축을 정리합니다.
  • KNIA/법령 근거를 RAG로 가져와 사고축에 맞는 기준만 표시합니다.
  • 일반 화면에는 쉬운 표현, 전문가 화면에는 판단 근거와 가감요소를 나눠 보여줍니다.

핵심 원칙

  • AI가 법적 결론을 확정하지 않습니다.
  • 영상 관찰값은 confidence와 frame reference를 갖춘 후보로 다룹니다.
  • 근거가 부족하면 “확정” 대신 조건부/보류 상태로 표시합니다.

Internal MCP-like Layer

MCP/Task-Plan-Goal의 현재 상태

14

현재 구현된 것

  • app/mcp/tool_registry.py: tool spec과 function registry
  • tool_executor.py: payload validation, scope validation, timeout/failure packet
  • agent_contracts.py: MCPToolSpec, MCPToolErrorPacket
  • Task plan, agent trace, goal result, quality packet이 safe metadata로 연결됨

의도적으로 과장하지 않는 것

  • 표준 MCP Host/Client/Server runtime은 아직 도입하지 않았습니다.
  • 외부 MCP 생태계와 연동 완료 상태가 아닙니다.
  • 현재는 Agent 내부 도구 경계와 trace 안정화를 위한 MCP-like 계층입니다.

표준 MCP 도입은 외부 tool server, cross-host reuse, 표준 MCP client 연결 요구가 생길 때 다시 검토하는 gate로 남겨져 있습니다.

Safety

안전성과 표시 정책

20

비밀정보 보호

  • 실제 .env, API key, JWT secret, NAS password는 출력/문서화하지 않습니다.
  • raw prompt, trace id, cache key, raw payload는 일반 사용자 화면에서 숨깁니다.
  • Android build artifact와 dist output은 직접 수정 대상이 아닙니다.

판단 안전장치

  • 사고축이 맞지 않는 KNIA/법령 근거는 goal conflict로 차단 또는 보류합니다.
  • 영상 observation이 사용자 진술과 충돌하면 confidence와 frame refs를 요구합니다.
  • 일반 화면에서는 “확정 판결”처럼 보이는 표현을 피하고, 필요한 보완 사실만 남깁니다.

LawCompass의 목표는 판결을 대신하는 것이 아니라, 사용자가 사고 직후 필요한 사실·근거·다음 행동을 정리하도록 돕는 것입니다.
